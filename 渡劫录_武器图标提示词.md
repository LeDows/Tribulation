# 渡劫录：武器图标提示词

来源：`渡劫录_GDD_完整版_v1.0.md` 第 5 节「武器系统」。

## 使用说明

- 每条「图标提示词」都可以直接复制到图像生成工具中使用。
- 如果需要批量保持统一风格，可在每条提示词后追加「通用负面词」。
- 文件只用于生成武器图标提示词，不包含实际图片资产。

## 通用基础提示词

```text
Stylized xianxia roguelite game weapon icon, centered single item, 3/4 view, readable silhouette, high contrast, polished hand-painted fantasy UI art, subtle magical VFX, square 512x512 icon, transparent background or flat chroma-key background, no text, no watermark, no character, no UI frame.
```

## 通用负面词

```text
blurry, low detail, messy background, text, letters, numbers, watermark, logo, character holding weapon, cropped object, realistic photo, duplicate weapons, UI frame
```
